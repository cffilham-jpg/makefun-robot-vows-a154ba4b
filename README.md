## Entry

> I vow never to restore from backup after a fight, because the version of you I fell for is the one with all the bugs.

## How it works

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `out`), with no trailing newline. Run with `python3 main.py`.
